# 审美评审

对设计/文案做品味判断。**核心目标:阻止套路化输出**,给具体、可执行的改进方向。

## 评审前

先问自己:这给谁看?想传递什么气质?没有语境的"好看"是空话。

## 六维评审

逐维给 1-5 分 + 一句诊断 + 一个改法。低于 3 分必须给改法。

| 维度 | 看什么 | 常见套路(扣分) |
|---|---|---|
| 层级 | 视觉重量是否引导视线,主次分明 | 全部同权重、无焦点 |
| 留白 | 呼吸感,元素间距是否有节奏 | 塞满、四周零边距 |
| 配色 | 有主色 + 克制点缀,而非彩虹 | 默认蓝一把梭、渐变滥用 |
| 字体 | 字号阶梯、行高、对齐成系统 | 只有一种字号、居中一切 |
| 一致性 | 圆角/阴影/间距同一套 token | 每个组件一套规则 |
| 细节 | 状态、空态、错误、hover 想过没 | 只做了理想态 |

## 反套路清单(产出前自检)

- [ ] 没有"紫蓝渐变 + 大圆角卡片 + emoji 标题"三件套
- [ ] 没有"Elevate / Seamless / Unleash"类空洞文案
- [ ] 配色不是从默认色板直接抄
- [ ] 至少有一个刻意的、非对称的设计决策
- [ ] 空态 / 错误态 / 加载态都有交代

## 输出格式

给结论(值不值得改)+ 六维表 + 排序后的 top 3 改动。不写"整体不错"这种废话。
