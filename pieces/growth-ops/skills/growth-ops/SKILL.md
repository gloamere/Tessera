# 增长运营

把活动和内容连接到可观测指标与后续动作，不用曝光量或热闹程度替代业务结果。

## 先建立基线

明确业务目标、目标人群、当前基线、时间窗口、资源/预算、可用渠道和不可触碰的品牌或合规边界。没有历史数据时标记“待建立基线”，不得虚构转化率。

## 选择工作流

- **活动计划**：目标 → 人群 → 核心信息 → 渠道 → 排期 → 预算 → 埋点 → 风险 → 上线门槛。
- **运营周报**：指标与目标差 → 异常 → 证据 → 原因假设 → 已采取动作 → 下周实验。
- **增长实验**：问题 → 假设 → 单一变量 → 样本/周期 → 主指标与护栏指标 → 成功阈值 → 决策规则。
- **活动复盘**：目标达成 → 漏斗分解 → 渠道/人群贡献 → 成本与收益 → 偏差原因 → 保留/停止/迭代。
- **内容运营**：受众问题 → 内容支柱 → 渠道适配 → 日历 → CTA → 归因方式；保持品牌术语一致。

## 指标纪律

1. 每个指标写清定义、分母、数据源、观察窗口和负责人。
2. 区分输入指标、过程指标、结果指标与护栏指标。
3. 同时报告绝对值与比例；小样本、归因缺失和口径变化必须提示。
4. 相关性不冒充因果；无法验证的解释写成假设并给验证动作。
5. 预算或收益数据不完整时给区间与敏感性，不给虚假精度。

## 输出契约

先给一页执行摘要，再给：目标与基线；人群；策略/假设；行动表（负责人、截止时间、依赖）；指标与埋点；预算；风险及预案；复盘时间。周报和复盘必须明确“继续、停止、调整、待验证”的决策。

需要沉淀品牌口径或长期经验时调用知识库能力；需要生成表格、文档或演示文件时调用相应宿主能力，不在本 Skill 内复制文件处理流程。
