# Gloamere Workflows 1.0.0

Initial official-directory submission for product and design leads.

- Compare product options from existing evidence and define the next validation.
- Review an existing interface with visible evidence and prioritized changes.
- Preserve decisions, research, and operating knowledge in an existing Markdown
  knowledge base.
- Respond in the user's language with first-class English and Chinese routing.

This is a skills-only package. It has no MCP server, custom UI, external
backend, telemetry, or authentication. Gloamere Eval, Debug Loop, UI System,
and other experimental candidates are not included.
