# Demo recording checklist

This checklist is dormant for the `v4.0.0` Git marketplace release. Use it only
after deciding to pursue an official-directory submission.

- Show the published package identity and three-Skill file tree.
- Run one English product-decision task.
- Run one Chinese visual-review task with a visible artifact.
- Run one knowledge-capture task against an isolated copy of an existing
  Markdown knowledge base.
- Show one negative request that does not activate the plugin.
- Confirm only the host surfaces required by the then-current submission form
  and supported by reproducible evidence. The current Git marketplace release
  verifies ChatGPT desktop and Codex CLI; it does not claim a self-hosted
  installation path on ChatGPT Work web.
- Do not show private source material, credentials, absolute local paths, or
  internal evaluation prompts.
- Paste the final HTTPS recording URL into `submission.json`.
