# Gloamere 插件与 Skill 准入参考

本参考只供维护者评估新增独立插件或 Skill，不参与运行时路由，也不替代真实 Codex 评测证据。

## 七维检查

| 维度 | 权重 | 高分证据 |
| --- | ---: | --- |
| 需求真实性与复用性 | 20 | 至少 3 次真实任务，并跨项目或场景复用 |
| 独特价值与增益 | 20 | Codex 宿主和现有 Skill 没有等价能力，质量收益可验证 |
| 触发边界与路由清晰度 | 15 | 使用场景、避免场景、冲突优先级及正反例明确 |
| 输出契约与可评测性 | 15 | 有固定契约、验收条件、失败行为和代表案例 |
| 轻量性与上下文成本 | 15 | 优先纯 Skill，无常驻服务和隐式状态 |
| Codex 兼容与维护成本 | 10 | 只依赖受支持的 Codex App、CLI 或 IDE 接口，并明确能力降级 |
| 安全性与透明度 | 5 | 权限、外部状态、失败行为和回退路径清晰可追踪 |

没有真实使用记录的候选最多进入实验区。主要只是重包装现有提示词或宿主能力的候选，不应独立发布。评分只用于维护决策，不能替代当前 SHA 的原型结果、身份锁和 native evidence。
