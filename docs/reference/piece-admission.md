# 拼图准入参考

本参考只供维护者在考虑新增独立插件或 Skill 时使用，不是运行时路由或自动门禁。

## 七维检查

| 维度 | 权重 | 高分证据 |
|---|---:|---|
| 需求真实性与复用性 | 20 | 至少 3 次真实任务，并跨项目或场景复用 |
| 独特价值与增益 | 20 | 宿主和现有 Skill 没有等价能力，质量收益可验证 |
| 触发边界与路由清晰度 | 15 | when/avoid、冲突优先级和正反例明确 |
| 输出契约与可评测性 | 15 | 有固定契约、验收、失败行为和代表案例 |
| 轻量性与上下文成本 | 15 | 优先纯 Skill，无常驻服务和隐式状态 |
| 跨宿主与维护成本 | 10 | Codex/Claude 使用同一事实来源并诚实降级 |
| 安全性与透明度 | 5 | 权限、外部状态、失败和回退明确可逆 |

没有真实使用记录的候选最多进入原型；主要是已有 prompt 或宿主能力重包装的候选不应独立发布。评分只是维护者决策参考，不能替代原型结果和 native eval 证据。
