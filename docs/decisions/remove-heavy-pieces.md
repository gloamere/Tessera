# 移除重型任务与语义代码拼图

## 决策

从 Tessera 市集、路由、安装白名单和仓库工作流中移除 `bd-tasks` 与语义代码 MCP 试点。两者引入的外部运行时、安装维护和上下文成本高于日常收益。

任务规划与跟踪使用宿主 Agent 的原生能力；代码检索与导航优先使用宿主和仓库已有工具。候选外部后端必须先证明轻量、可选且有明确净收益，才可重新作为拼图提案。

## 清理范围

- 删除两块拼图及双端市集条目。
- 删除任务后端的信任安装项和仓库内持久化元数据。
- 从核心路由、策划拼图、部署文档与产品说明中删除入口。
- 保留通用 MCP 候选研究，但不默认落地任何重型服务。
