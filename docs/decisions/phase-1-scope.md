# 第一阶段：纯 skills 路由网关

## 决策

Tessera 第一阶段以「拼图管理 + 任务路由 + 按需调用拼图协助完成任务」为核心。`tessera-core` 是纯 skills 插件，不包含 hooks、常驻服务、Go/Node 二进制或 release 下载链路。

## 执行原则

- 简单、明确、低风险任务由当前 Agent 直接完成。
- 单一但专业性强的任务（例如 UI 评审）仅在收益大于 token 和等待成本时调用对应拼图。
- 复杂任务先路由；只有可独立拆分、宿主支持且并行净收益为正时才委派子代理。
- 会话内计划与跟踪使用宿主原生能力，不引入外部任务后端。
- 外部能力必须经用户确认安装；状态必须如实披露。

## 演进边界

这份文档是第一阶段的指导，不是永久架构锁定。后续可以基于真实使用数据调整路由规则、增加拼图种类、接入新的客户端或可视化能力；任何扩展都应保持可选、透明、可验证，且不倒退为隐式安装或强制任务后端。
